# Ankush — Developer & Creator Portfolio

A dark-themed, motion-crafted portfolio website showcasing full-stack systems, creative problem solving, AI explorations, and interactive design.

## 🚀 Features

- **Cinematic Video Intro**: Autoplaying responsive intro overlay.
- **Dual-Layer Framing & Dynamic Typography**: Layered depth architecture (`HELLO / MEET / ANKUSH`) with smooth pop-out entrance and floating typography.
- **Interactive Handwritten Mindset**: Seamless philosophy quote transition with Google Caveat cursive typography.
- **Fixed Center Services Roller**: Two-column scroll runway with sticky headline anchoring and depth-of-field blur on focus.
- **Pinned Pinboard Projects Collage**: Staggered scroll-driven cards with dynamic collage overlap, elevation focus on hover, and direct project links.
- **"Before You Ask..." Q&A Section**: Asymmetric 3-column FAQ layout with high-contrast typography and red accents.
- **Interactive Footer with Upside-Down Watermark**: Seamless navigation, smooth back-to-top transition, and faint bottom watermark (`DREAMING`).
- **Interactive Easter Egg**: Floating 3D camera widget with realistic full-screen flash and smooth decay.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (Grid, Flexbox, Sticky positioning, CSS Variables), Vanilla JavaScript (ES6+)
- **Backend**: Node.js, Express.js
- **Design Philosophy**: Solid `#000000` dark theme, `#ff3b30` crimson accents, seamless page transitions

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation & Running Locally

1. Clone or download the repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd PortfolioFinall
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
